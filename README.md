**Task 1: Inputdisplay.java / displayindics.java**
Takes array input from user and displays elements with index.
Time Complexity: O(n)

**Task 2: SUMANDAVERAGE.java**
Calculates sum and average of array elements.
Time Complexity: O(n)

**Task 3: MAXVALUE.java & MINVALUE.java & SECONDmin.java**
Finds maximum, minimum and second minimum value without using built-in functions.
Time Complexity: O(n)

**Task 4: numbernotfound.java**
Linear search - searches element and returns index. If not found, shows message.
Time Complexity: O(n)

**Task 5: insertelement.java**
Inserts new element at given position by shifting elements to right.
Time Complexity: O(n)

**Task 6: deleteelement.java**
Deletes element at given index and shifts remaining elements to left.
Time Complexity: O(n)

**Task 7: duplicateelement.java**
Finds duplicate elements in array and counts occurrences.
Time Complexity: O(n^2)

**Task 8: sortarray.java**
Sorts array in ascending and descending order using Bubble Sort.
Time Complexity: O(n^2)

**Task 9: meregetowarray.java**
Merges two arrays into third array and finds largest element in merged array.
Time Complexity: O(n1+n2)

**Task 10 & Task 11: TASK11.java**
Merge Two Sorted Arrays in sorted form, third array should remain sorted. No sorting algorithm applied.
Uses Two-Pointer Technique (Merge step of Merge Sort).
Time Complexity: O(n1 + n2)
Space Complexity: O(n1 +n2)
